# 项目经验

以下要点来自一次完整角色制作、另一个 Avatar 候选与材质任务，以及同一项目的 Mac → Windows 交接和成年魂调研。

| 阶段 | 可复用结论 |
|---|---|
| 参考图 | 带头发的头部、带服装的身体，各做正背左右。用全身对照图固定头身、脚底和比例。原画没给出的背面细节单独确认。 |
| 候选和分件 | 每组可以准备多个候选。示例使用 P2.0、25,000 四边面目标，每组四个。由用户选定。若脸与后发或衣服上下相连，先检查更细的分割能否得到可贴图的独立区域。 |
| 饰品返工 | 心形发夹融合到刘海后，先清理参考图，再生成干净的头模。独立制作发夹，刚性跟随头骨。关闭发夹检查残留，装回后检查正面和斜侧。 |
| 材质和绑定 | UV、底色、比例和部件归属在绑定前确认。角色实例使用了 4K 底色与 VRM 1.0 骨骼。摆动和固定部件分别设定。 |
| 权重与物理 | 骨架、蒙皮、动作和物理分开验收。走路看发束和裙摆，抬腿看穿插，转头看发夹。案例曾验证 10 条摆动链的物理响应。 |
| L4D2 | 从母版建立独立移植副本。Rochelle 第三人称模型完成骨架对齐、减面、限制权重、材质和编译输入，SMD 已在 Mac 回读。Windows 工具编译及实机表现应按目标机器核实。 |
| 第一人称 | 用户观察到第一人称仍是 Rochelle 原版手臂。手臂有独立资源路径和参考姿势。这个版本提供可选的手臂 QC 编译入口，手臂素材须先准备。 |
| 成年魂 | 首版范围是主线游玩、玩家操控、默认成年外观。已有社区先例。项目本身完成了可行性调研，资产路径、兼容构建和实际运行需要在目标版本确认。 |

示例角色的图像、模型与项目包留在原工作区。工具包可从新角色的本地输入开始。
