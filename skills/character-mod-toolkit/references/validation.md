# 建模、移植与交接验收

每次验收都关联当前输入、阶段产物和实际工具运行记录。角色母版、移植工作副本和游戏最终包各自保留路径，避免把旧构建误当成新成果。

## 参考图和网格

- 正、背、左、右分别标注角色方向，确认没有误用镜像。对照眼睛、头发轮廓、耳朵、服装结构和独立饰品。原图看不到的区域由用户确认补全方案。
- 候选按相同角度和缩放截图。检查指缝、发束、裙边、头颈接合、局部穿插和粘连。饰品返工时保留无遮盖画面及装回后的正面、斜侧。关闭独立发夹后，头发上应看不到原先的发夹形状。
- 在目标导出格式上检查三角面、法线、退化面和孤立顶点。需要减面时优先检查轮廓、手部和容易形变的区域，再用实际编译器验证目标限制。

## 材质、绑定和动作

- 对照材质槽、UV、贴图路径、颜色空间、透明或遮罩模式和双面渲染。原始贴图与游戏转换贴图分别记录。导出后在干净场景回读，确认所有外部贴图都能找到，检查不同角度和光照下的发片、睫毛与衣摆。
- 核对骨名、父子层级、参考姿势、单位、朝向和根骨变换。检查缺权重、非有限权重、归一化、每顶点骨骼影响上限，以及手指与装备挂点。上限以目标游戏和格式为准。
- 看站姿、转头、走跑、蹲起、抬腿和手指弯曲。马尾与裙摆需要观察摆动、回正、碰撞和穿插。发夹等硬饰品检查是否稳定跟随目标骨骼。角色格式中的弹簧骨和碰撞设置需要在游戏目标中重新验收。
- 在第一人称视角测试袖口、手腕、手指和持握。把独立视图模型作为一个有自己骨架、材质和包内路径的产物检查。第三人称结果不能作为第一人称验收依据。

## 记录验证等级

| 等级 | 要保留的证据 |
|---|---|
| 素材就绪 | 用户确认的参考、目标及变更范围，附版本或可重现的输入路径。 |
| 建模预览 | 当前模型的正、斜侧、背面或动作预览，注明使用的软件与动作。 |
| 导出回读 | 文件名、读取工具版本、关键网格/骨骼/材质结果与异常。 |
| 原生编译 | 目标游戏构建、编译器、当前运行日志和本次产物。 |
| 打包核对 | 包内目标路径、文件列表与对应编译产物的校验值。 |
| 游戏验收 | 实际平台和构建、测试场景及观察到的通过项和问题。 |

失败时记录最早的实质错误、触发命令和现有产物。定位到对应步骤后再重试。报告中注明未运行的步骤和缺失依赖。不要用离线预览、第三方先例或上一次编译的包代替本次实机验证。

## 换机交接

携带可编辑母版、实际游戏移植副本、编译输入、材质、构建说明、依赖版本、技能入口和最近的验证摘要。使用项目根目录下的相对路径，必要的安装路径留到目标电脑定位。标注下一步操作、已批准的角色和范围，以及明确留在后续的内容。

目标机器安装自己的游戏与编译工具，先验证相对路径和新构建输出。准备发布前，检查包里只包含当前游戏目标需要的文件和用户有权分发的资产。保留安装、卸载和回滚方式。
